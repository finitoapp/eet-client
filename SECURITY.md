# Security policy

Bezpečnostní zranitelnosti prosím neoznamujte veřejným issue.

Pro zodpovědné nahlášení napište na **pepakriz@gmail.com**, případně použijte
GitHub [private vulnerability reporting](https://github.com/finitoapp/eet-client/security/advisories/new).
V hlášení prosím uveďte:

- verzi balíčku a runtime (Node.js/Bun/Deno/prohlížeč),
- minimální reprodukovatelný příklad — bez reálného produkčního certifikátu
  nebo privátního klíče; sdílené playground přihlašovací údaje v
  [`caeet/`](./caeet) lze použít volně (viz README, sekce „Bezpečné nakládání
  s certifikáty“),
- očekávané vs. skutečné chování a případný dopad.

Na hlášení se snažíme reagovat do několika pracovních dnů. Po ověření a
opravě zveřejníme GitHub security advisory s poděkováním nahlašovateli,
pokud si nepřeje zůstat anonymní.
